# Meridian — мировой рыночный терминал

Опубликован на https://esforgary.github.io/market-analysis/ и работает без включённого ПК.

## Данные и частота обновления

- 103 публичные RSS/Atom-ленты от 38 редакций и организаций. Реестр — `lib/news-sources.ts`, правила отбора — `SOURCE_POLICY.md`.
- GitHub Actions запускает сбор по расписанию каждые 5 минут. Возможны задержки очереди и развёртывания; это не гарантированная доставка за 5 минут и не поток в реальном времени. Неактивные публичные репозитории могут терять scheduled runs по правилам GitHub.
- Открытая видимая страница проверяет опубликованный снимок каждые 5 секунд. Кнопок ручного обновления нет. Если сбор старше 15 минут, появляется предупреждение.
- До 8 запросов одновременно, тайм-аут 12 секунд, условные запросы ETag/Last-Modified. Кеш предыдущих ответов сохраняется GitHub Actions по часовым ключам. При отказе сохраняются прежние материалы с исходными датами, а лента отмечается как недоступная.
- Раздел «Источники» показывает число подключённых/ответивших лент, организации, последнюю проверку, успешную загрузку и дату публикации. Число лент не равно числу независимых издателей.
- Дубли удаляются по URL и заголовку. Новости старше 30 дней не включаются в общую выдачу нового сбора. Идеи дня используют только последние 72 часа, исключая будущие даты.
- TradingView автоматически обновляет котировки своего источника; возможны задержки биржи. Виджет не отдаёт цены алгоритму анализа приложения.
- Frankfurter — дневные справочные курсы. Проверка каждые 5 секунд не делает их тиковыми котировками.

## Интерфейс

77 акций, 12 облигационных и дивидендных ETF; 40 основных валют и остальные доступные в Frankfurter. Поиск, фильтры, избранное, подробные графики, светлая/тёмная/системная тема, адаптивный интерфейс. Баннер новостных идей, аргументы, риски и короткие RSS-выдержки со ссылками под графиком. RSS-аннотации переводятся на русский; оригинал доступен для сверки. Избранное и тема хранятся только в браузере.

Идеи — прозрачная эвристика заголовков, не валидированная модель доходности. Она не оценивает цену входа. Корпоративные пресс-релизы отражают позицию эмитента. Валютные сценарии экстраполируют историю и не учитывают новостные шоки. Дивидендного календаря и персональных рекомендаций нет.

## Разработка и публикация

Node.js 24. `npm ci`, затем `npm run dev:pages` для статической версии либо `npm run dev` для серверной.

`npm run build:pages` собирает новости и создаёт `dist-pages/`. Workflow `.github/workflows/pages.yml` публикует после push, ручного запуска и по расписанию. Settings → Pages → Source: GitHub Actions.

`npm run build` создаёт серверную Cloudflare-совместимую сборку. `/api/market` объединяет одновременные запросы, хранит кеш в памяти и обновляет его не чаще одного раза в 5 минут. Это обработчик по запросу, а не постоянно работающий фоновой демон.

Проверки: `npm run test:market`, `npx tsc --noEmit`, `npm run build:pages`.

Для настоящего фонового сбора с секундной задержкой необходим отдельный постоянно работающий облачный сборщик и соответствующие источники/API. GitHub Pages сам серверный код не выполняет.

## Русские краткие версии и фон

Фоновые сферы используют независимые случайные траектории, размеры и длительности 24–44 секунды, постепенно появляются и угасают. В скрытой вкладке анимация приостанавливается; при prefers-reduced-motion остаётся статичный фон.

Сборщик поддерживает перевод заголовков и контекстных RSS-аннотаций через DeepL API. Внешнему сервису передаётся только общедоступный текст RSS. Для включения добавьте ключ в GitHub → Settings → Secrets and variables → Actions → New repository secret → `DEEPL_AUTH_KEY`. Ключ используется только в GitHub Actions и не попадает в сайт или репозиторий. Free-ключи с суффиксом `:fx` используют api-free.deepl.com, остальные — api.deepl.com. Без ключа сайт честно показывает «русский перевод не подключён». При ошибке показывается оригинал; при отказе авторизации, лимите или исчерпанной квоте обработка прекращается. Переводы кешируются по хешу текста и переиспользуются из предыдущей публикации. За запуск — до 40 новостей в пределах 90 секунд; свежие новости идут первыми. Стоимость и квоты зависят от аккаунта провайдера.

Это машинный перевод краткого текста RSS, а не проверенный человеком пересказ всей статьи. Сборщик сохраняет целые предложения и старается включать оговорки и риски из длинных аннотаций. Изменение или потеря чисел блокирует перевод; такая проверка не гарантирует сохранение всех смысловых нюансов. Полный контекст и условия доступны по ссылке на оригинал; в карточке можно раскрыть исходный текст. Полные платные статьи не загружаются и ограничения доступа не обходятся.

Первое обнаружение означает первое зафиксированное получение материала нашим сервисом с момента введения этой функции, а не первое появление новости во всём интернете.

API: https://developers.deepl.com/api-reference/translate/request-translation
