# Meridian

Личный терминал обзора рынков: Next-compatible React / Vinext, TypeScript.

## Запуск

`npm ci` затем `npm run dev`. Production: `npm run build`.

## Данные

`GET /api/market`: RSS ФРС, ЕЦБ, TechCrunch, дневные курсы и годовая история Frankfurter. Ключи не нужны. Обновление вручную; кэш 5 минут, при ошибках 30 секунд. Источники вызываются независимо с таймаутами. Заголовки отображаются как текст, ссылки ограничены HTTP(S). Ошибки источников видны пользователю.

Первое открытие показывает явно помеченные демонстрационные данные. Нажмите «Обновить данные» для загрузки источников. Отсутствие источника не подменяется вымышленными новостями.

Избранное сохраняется только в текущем браузере. Персональные финансовые данные не собираются.

## Ограничения

Это первая версия аналитического терминала, не валидированная торговая модель. Лексическая тональность заголовков не означает направление движения цены. Справочные активы не являются рекомендациями. Не подключены текущие цены акций, цены и доходности облигаций, подтверждённые даты/суммы дивидендов. Для этого нужен лицензированный поставщик. Персональная стратегия требует ввода целей и риск-профиля. Прогнозный сценарий валют основан только на экстраполяции исторических логарифмических доходностей, не на причинном анализе новостей.
