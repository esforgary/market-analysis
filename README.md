# Meridian — мировой рыночный терминал

Опубликован на https://esforgary.github.io/market-analysis/ и работает без включённого ПК.

## Данные и частота обновления

- 103 публичные RSS/Atom-ленты от 38 редакций и организаций. Реестр — `lib/news-sources.ts`, правила отбора — `SOURCE_POLICY.md`.
- GitHub Actions запускает сбор по расписанию каждые 5 минут. Возможны задержки очереди и развёртывания; это не гарантированная доставка за 5 минут и не поток в реальном времени. Неактивные публичные репозитории могут терять scheduled runs по правилам GitHub.
- Открытая видимая страница проверяет опубликованный снимок каждые 5 секунд. Кнопок ручного обновления нет. Если сбор старше 15 минут, появляется предупреждение.
- До 8 хостов одновременно, не более одного запроса на хост с интервалом 250 мс между лентами. Тайм-аут 12 секунд, одна повторная попытка для сетевой ошибки или HTTP 5xx; HTTP 403 не повторяется и не обходится сменой идентификатора. Условные запросы ETag/Last-Modified привязаны к URL ленты. Кеш предыдущих ответов сохраняется GitHub Actions по часовым ключам. При отказе сохраняются прежние материалы с исходными датами, а лента отмечается как недоступная.
- Раздел «Источники» показывает число подключённых/ответивших лент, организации, последнюю проверку, успешную загрузку и дату публикации. Число лент не равно числу независимых издателей.
- Дубли удаляются по URL и заголовку. Новости старше 30 дней не включаются в общую выдачу нового сбора. Идеи дня используют только последние 72 часа, исключая будущие даты.
- Собственные SVG-графики акций/ETF используют OHLC Yahoo Finance. Внутридневные серии запрашиваются раз в 15 минут, дневная и недельная история — раз в 6 часов. Это датированные снимки с возможной задержкой, а не тиковый поток. Браузер проверяет опубликованные файлы каждые 5 секунд. TradingView доступен внешней ссылкой.
- Валюты — дневные данные через Frankfurter: для выбранных пар с UAH закреплён НБУ, для остальных используются сводные курсы. Проверка каждые 5 секунд не делает их тиковыми котировками.

## Интерфейс

77 акций, 12 облигационных и дивидендных ETF; 40 основных валют и остальные доступные в Frankfurter. Поиск, фильтры, избранное, подробные графики, светлая/тёмная/системная тема, адаптивный интерфейс. Баннер новостных идей, аргументы, риски и короткие RSS-выдержки со ссылками под графиком. При подключённом DeepL API RSS-аннотации переводятся на русский; оригинал доступен для сверки. Избранное и тема хранятся только в браузере.

Идеи — прозрачная эвристика заголовков и RSS-описаний, не валидированная модель доходности. Она не оценивает цену входа. Корпоративные пресс-релизы отражают позицию эмитента. Валютные сценарии экстраполируют историю и не учитывают новостные шоки. Дивидендного календаря и персональных рекомендаций нет.

## Разработка и публикация

Node.js 24. `npm ci`, затем `npm run dev:pages` для статической версии либо `npm run dev` для серверной.

`npm run build:pages` собирает новости и создаёт `dist-pages/`. Workflow `.github/workflows/pages.yml` публикует после push, ручного запуска и по расписанию. Settings → Pages → Source: GitHub Actions.

`npm run build` создаёт серверную Cloudflare-совместимую сборку. `/api/market` объединяет одновременные запросы, хранит кеш в памяти и обновляет его не чаще одного раза в 5 минут. Это обработчик по запросу, а не постоянно работающий фоновой демон.

Проверки: `npm run test:market`, `npx tsc --noEmit`, `npm run build:pages`.

Для настоящего фонового сбора с секундной задержкой необходим отдельный постоянно работающий облачный сборщик и соответствующие источники/API. GitHub Pages сам серверный код не выполняет.

## Русские краткие версии и фон

Фоновые сферы используют независимые случайные траектории, размеры и длительности 24–44 секунды, постепенно появляются и угасают. В скрытой вкладке анимация приостанавливается; при prefers-reduced-motion остаётся статичный фон.

Сборщик поддерживает перевод заголовков и контекстных RSS-аннотаций через DeepL API. Внешнему сервису передаётся только общедоступный текст RSS. Для включения добавьте ключ в GitHub → Settings → Secrets and variables → Actions → New repository secret → `DEEPL_AUTH_KEY`. Ключ используется только в GitHub Actions и не попадает в сайт или репозиторий. Free-ключи с суффиксом `:fx` используют api-free.deepl.com, остальные — api.deepl.com. Без ключа сайт честно показывает «русский перевод не подключён». При ошибке показывается оригинал; при отказе авторизации, лимите или исчерпанной квоте обработка прекращается. Переводы кешируются по хешу текста и переиспользуются из предыдущей публикации. За запуск — до 40 новостей в пределах 90 секунд; свежие новости идут первыми. Стоимость и квоты зависят от аккаунта провайдера.

Это машинный перевод краткого текста RSS, а не проверенный человеком пересказ всей статьи. Сборщик сохраняет целые предложения и старается включать оговорки и риски из длинных аннотаций. Изменение или потеря чисел блокирует перевод; такая проверка не гарантирует сохранение всех смысловых нюансов. Полный контекст и условия доступны по ссылке на оригинал; в карточке можно раскрыть исходный текст. Полные платные статьи не загружаются и ограничения доступа не обходятся.

Первое обнаружение означает первое зафиксированное получение материала нашим сервисом с момента введения этой функции, а не первое появление новости во всём интернете.

API: https://developers.deepl.com/api-reference/translate/request-translation

## Интерфейс и движение

Новостной баннер высотой около 470 px на компьютере и 480 px на телефоне использует бирюзово-фиолетовый градиент и плавное перекрытие слайдов. Есть стрелки, индикаторы, горизонтальный свайп и пауза; автоматическое переключение останавливается при наведении, фокусе, скрытой вкладке и системном уменьшении движения. Высота не меняется при перелистывании.

У всех 89 активов есть локальная SVG-иконка: 45 логотипов Simple Icons, 32 монограммы компаний и 12 обозначений ETF. Валюты используют векторные символы. Атрибуция — public/icons/ATTRIBUTION.md. Внешние запросы за логотипами не нужны.

Кнопки, навигация, диалоги и раскрытие оригиналов используют согласованные переходы с поддержкой prefers-reduced-motion. Собственный график сохраняет размеры при переключении режима; системные меню выбора управляются браузером.

Уведомления о задержках и сбоях источников кратко появляются в углу, затем доступны через колокольчик в верхней панели. Журнал хранит последние 50 событий в localStorage этого браузера, отмечает восстановление и не дублирует постоянный сбой при проверках или перезагрузке. Методология открывается одной кнопкой ⓘ в верхней панели.

Строка каталога открывает график при нажатии на любую её область; избранное работает отдельно. Валютный срез находится на обзоре. При прокрутке появляется боковая панель курсов, а на узких экранах — компактная раскрывающаяся кнопка.

## Материалы интерфейса и валютные источники

Графитовая тема использует объёмные поверхности, мягкую подсветку краёв и стеклянные переключатели. Свечение валютной линии — #28e22f при росте и #e32636 при падении за выбранный период. Линия плавно соединяет реальные наблюдения; подсказка показывает исходное значение и дату в UTC. Цвет обозначает изменение выбранной пары, а не рекомендацию к покупке.

Валютная история и последняя цена запрашиваются с одинаковыми base, quote и providers. Для UAH на любой стороне пары используется providers=nbu. Новая фактическая точка добавляется в историю или заменяет точку с той же датой; будущие, повреждённые и чужие записи отбрасываются. Наблюдения не создаются для пропущенных дней. Если НБУ не покрывает пару, приложение показывает недоступность, а не незаметно заменяет источник.

Общий каталог остаётся сводным и сохраняет широкий список валют. Выбранная карточка использует ту же цену, что и график, и помечена своим источником. Frankfurter по умолчанию смешивает поставщиков; [документация](https://frankfurter.dev/#filtering-by-provider). Значения Google/Morningstar, банковского обменника и официального НБУ могут различаться. Сравнивать нужно поставщика, пару, дату и тип курса; совпадение со сторонним графиком не обещается.


## Новостной радар и диагностика RSS

Карусель включает все активы каталога, распознанные в публикациях за 72 часа, без ограничения двумя или пятью карточками. На ней указан фактический охват: число активов, число активов с позитивным поводом и количество свежих публикаций. Позитивные, смешанные, негативные и нейтральные события различаются отдельными отметками. Сначала идут позитивные поводы, затем смешанные сигналы, риски и наблюдения; внутри группы учитываются разнообразие издателей, число публикаций (с ограниченным весом) и свежесть. Это порядок изучения новостей, не рейтинг доходности.

`lib/news-analysis.ts` распознаёт названия и алиасы всех 89 инструментов, тикеры с биржей и контекст из RSS. Корпоративный издатель может подсказать эмитента, но не создаёт позитивный сигнал. Материал о нескольких компаниях остаётся нейтральным: общая оценка не назначается каждой из них. Простые упоминания роста, гипотезы и старые запуски продуктов сами по себе не дают позитивного повода. Правила эвристические; полная статья не анализируется. Новость на позитивной/негативной карточке соответствует её аргументу и ведёт к оригиналу.

Сборщик берёт до 50 последних по дате материалов из каждой ленты и повторно классифицирует кеш, включая ответы 304. Экран источников группирует реальные причины: отказ доступа, лимит запросов, отсутствующий адрес, ошибка сервера, тайм-аут, ошибка формата или соединения. Несколько RSS одной организации не означают несколько независимых источников.

В проверке 17 сентября 2026 года доступны 88 из 103 лент (36 из 38 организаций). BLS отклоняет 12 запросов, FTC — 3, все с HTTP 403. Адреса совпадают с официальными RSS-каталогами. Они остаются в реестре и отмечены как ограниченные; получить разрешение поставщика нужно отдельно.

## Яркое стекло и собственные графики

Палитра — глубокий navy, cyan, electric blue и pink-violet; слой components/liquid-glass.css заменяет зелёно-серые материалы. Биржевой график рисуется локально SVG: точные закрытия баров, свечи OHLC, объёмы, подсказки по наведению/касанию, клавиатура и полноэкранный режим. Glow применяется к самой линии двумя уровнями размытия, поверх остаётся чёткий контур. Валютная линия получила такое же усиленное свечение. Встроенных iframe TradingView больше нет.

Файлы котировок собирает scripts/snapshot-securities.mjs: 5m/5d, 60m/1mo, 1d/5y и фактические недельные данные за доступную историю. Поставщик — публичный chart endpoint Yahoo Finance; это не документированный стабильный сторонний API, доступность может меняться. [Информация Yahoo об источниках и задержках](https://help.yahoo.com/kb/SLN2310.html). Снимки и кеш сохраняют время каждого набора, метаданные и ошибки. Отказы 401/403/429 не обходятся; при отказе остаются датированные прежние данные, если они были. Неполные OHLC, чужие тикеры и будущие наблюдения отбрасываются.

Результаты генерируются в public/data/securities/ и не коммитятся; GitHub Actions переносит .securities-cache.json между запусками. Первая сборка получает полную историю, последующие обновляют наборы по TTL. Цены выражены в валюте поставщика: GBp означает пенсы, а не GBP. Диапазоны 1Ч/1Д/5Д опираются на реальные торговые сессии; недостающие точки не дорисовываются. Изменение цены не учитывает дивиденды и не является доходностью стратегии.

Каталог Roche обновлён с ROG на ROP согласно [официальному сообщению о смене тикера 17 марта 2026](https://www.roche.com/investors/updates/inv-update-2026-03-16); старые записи избранного мигрируют при загрузке.
